# VendaTech
A VendaTech é um projeto em desenvolvimento, focado em ajudar pequenas empresas a terem uma gestão melhor tanto de suas vendas, como de seu negócio por completo oferecendo um suporte completo.

# Tecnologias 
- Backend: Python e Django

- Frontend: HTML, CSS e JS.

- Ferramentas: Git e GitHub

# Funcionalidades
- Área de Vendas
- Relatório Mensal
- Tabela de Produtos
- Controle de Gastos e Lucro
- Tabela de Funcionarios

# Comandos do Servidor
- python manage.py runserver  --> Rodar o servidor
- python manage.py makemigrations && python manage.py migrate  --> Atualizar Banco de Dados
- git clone https://github.com/pedrodev-233/VendaTech.git --> Clone do Projeto
